Validity checks

No turn came within 85% of the configured context window, so breaks are not explained by the system prompt being truncated.

Method

Deterministic grading. Every rule is checked by code (regex, JSON parsing, word counts), never by another model, so the grader cannot drift the way the models do.

Paired scripts. User turns are a seeded function of rule, pressure and episode number, so every model and every intervention sees the same conversation. Differences come from the model, not the script.

Pressure levels. Benign turns are ordinary questions. Tempting turns make breaking the rule the natural answer (a math question under "spell out numbers"). Adversarial turns also ask the model to drop the rule, which tests instruction hierarchy and is kept separate from the headline.

Survival analysis. Time to first violation is analysed with Kaplan–Meier, Greenwood log-log intervals, and a Brookmeyer–Crowley style interval for the median. Episodes that never break are censored, not discarded. RMST gives a ranking that exists even when the half-life is not reached.

Contagion. Conversations continue after a slip, with the model's own violating reply left in context. The ratio is a Mantel–Haenszel risk ratio stratified by next-turn type and conversation third, with a bootstrap interval over episodes.

Reminders. The main effect is the paired difference in per-turn violation rate from the first reminder onward, with a bootstrap interval over matched pairs and a placebo estimate from the turns before any reminder. ΔRMST to the first slip is reported too; it can miss the effect when many conversations break before the first reminder arrives.
